# KV_LOKRA


# 📁 Secure Data Collection Form (WAMP & PHP)

A lightweight, full-stack data collection system built using **HTML, CSS, PHP, and WAMP/MySQL**. This project allows users to submit information securely through a clean web interface, which is then processed and stored directly in a local database.

---

## 🚀 Features
* **Clean & Responsive UI:** User-friendly HTML/CSS form interface.
* **Backend Processing:** PHP scripts to handle form submissions securely (`submit.php`, `records.php`).
* **Database Integration:** Direct data storage into a local MySQL database via WAMP server.
* **Network Testing:** Successfully tested and deployed locally using **ngrok** to collect remote responses.
